# Actai

واجهة أولية عربية لمساعد ذكاء اصطناعي شامل، بتصميم محادثة من اليمين إلى اليسار.

## مشروع Learn English With Alex
أُضيف تطبيق تعليمي مستقل لتعلّم الإنجليزية من الصفر إلى B2، مع مقدمة وفهرس عربي وشرح مبسّط للقواعد بالعربية وأمثلة إنجليزية.

- [فتح التطبيق التعليمي](learn-english-with-alex/app.html)
- [دليل المشروع](learn-english-with-alex/README.md)
- [نسخة الكتاب بتقليب الصفحات](learn-english-with-alex/index.html)

## تشغيل الواجهة الأصلية
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع.

## الملفات الأصلية
- `index.html`: هيكل التطبيق.
- `styles.css`: التصميم المتجاوب.
- `app.js`: تفاعلات المحادثة الأولية.

## الحالة الحالية
هذه نسخة واجهة تجريبية فقط. الردود داخلها توضيحية؛ لم يتم بعد ربط نموذج ذكاء اصطناعي أو خدمات تنفيذ الأوامر.
