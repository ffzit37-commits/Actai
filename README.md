# Actai

واجهة أولية عربية لمساعد ذكاء اصطناعي شامل، بتصميم محادثة من اليمين إلى اليسار.

## تشغيل الواجهة
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع.

## الملفات
- `index.html`: هيكل التطبيق.
- `styles.css`: التصميم المتجاوب.
- `app.js`: تفاعلات المحادثة الأولية.

## الحالة الحالية
هذه نسخة واجهة تجريبية فقط. الردود داخلها توضيحية؛ لم يتم بعد ربط نموذج ذكاء اصطناعي أو خدمات تنفيذ الأوامر.

## الخطوات التالية
1. بناء خادم خلفي آمن للمحادثات.
2. ربط نموذج ذكاء اصطناعي ومزودات قابلة للتبديل.
3. إضافة تنفيذ المهام وإنشاء الملفات مع صلاحيات ومراجعة.
4. تطوير توليد الفيديو وفق النماذج وموارد التشغيل المتاحة.
