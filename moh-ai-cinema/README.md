# CINEMORA AI
استوديو ويب وتطبيق Android لتجربة قص الفيديو والدبلجة.

## ما يعمل في هذه المرحلة
- اختيار فيديو محلي وعرضه ومعرفة مدته وأبعاده.
- تحديد بداية ونهاية مقطع ومعاينته.
- تسجيل المقطع أثناء تشغيله وتصديره بصيغة WebM عبر MediaRecorder في المتصفحات المدعومة.
- معاينة نطق نص باستخدام أصوات الجهاز المتاحة بلغات متعددة.
- واجهة عربية متجاوبة قابلة للتثبيت كتطبيق ويب وبناؤها كتطبيق Android عبر Capacitor.

## حدود مهمة
هذه نسخة تأسيسية وليست بديلاً مكتملاً لـ Miqla بعد. لا يوجد حتى الآن تحليل آلي للمقاطع، أو دبلجة مدمجة داخل ملف الفيديو، أو استنساخ صوت، أو مزامنة شفاه، أو ترميز 4K حقيقي. معاينة الكلام لا تُدمج في الفيديو. تصدير المقاطع يعتمد على دعم المتصفح لـ MediaRecorder وقد يتأثر بالذاكرة وطول الملف.
لن ندّعي وجود معالجة AI أو جودة 4K قبل إضافة محرك معالجة واختباره فعلياً.
