# MOH AI CINEMA
نسخة تجريبية عربية لتخطيط الفيلم وإنتاج فيديو موشن تجريبي مباشرة داخل المتصفح أو تطبيق Android.

## ما يعمل الآن
- إدخال فكرة الفيلم واختيار النوع واللغة والمدة والأسلوب.
- إنشاء مخطط من 8 فصول و32 مشهداً مع تعليمات بصرية.
- حفظ المشروع محلياً وتصديره بصيغة JSON.
- رسم مشاهد سينمائية متحركة على Canvas.
- تسجيل المشاهد في ملف فيديو WebM مع خلفية صوتية إلكترونية مولّدة محلياً.
- معاينة الفيديو الناتج وتنزيله من الهاتف أو المتصفح.
- لا يحتاج هذا المسار التجريبي إلى مفتاح API أو إيداع مالي.

## حدود النسخة الحالية
الفيديو الناتج هو مونتاج رسوم سينمائية متحركة مستندة إلى عناوين وأوصاف المشاهد، وليس لقطات بشرية أو مواقع واقعية مولّدة بالذكاء الاصطناعي. مدة الفيديو الحالية تعتمد على عدد المشاهد والمدة المختارة لكل مشهد، ولا تنتج بعد فيلماً كاملاً مدته 40 دقيقة.
لإضافة توليد فيديو واقعي، يلزم ربط مزوّد فيديو خارجي بخادم آمن. لا تضع مفاتيح API داخل ملفات الواجهة أو APK؛ احفظها كأسرار خادم، وانتبه إلى حصص الاستخدام والتكلفة.

## البناء
يُبنى APK تجريبي تلقائياً بواسطة GitHub Actions عند دفع تغييرات إلى فرع `moh-ai-cinema`. الملف الناتج APK تجريبي Debug وليس إصداراً موقعاً للنشر على المتجر.
