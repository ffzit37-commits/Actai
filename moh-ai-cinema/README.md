# MOH AI CINEMA
نسخة أولية عربية لتخطيط إنتاج فيلم طويل من فكرة واحدة، مع تجهيز مشروع Android APK عبر GitHub Actions.

## ما يعمل الآن
- إدخال فكرة الفيلم واختيار النوع واللغة والمدة والأسلوب.
- إنشاء مخطط من 8 فصول و32 بطاقة مشهد.
- إنشاء وصف توجيهي سينمائي لكل مشهد.
- حفظ المشروع محلياً وتصديره بصيغة JSON ونسخ تعليمات المشاهد.
- واجهة عربية RTL مناسبة للهاتف.

## ما لا يعمل بعد
هذا الإصدار لا يولّد ملفات فيديو أو أصوات فعلية. يلزم ربط مزوّد توليد فيديو وصوت عبر خادم آمن. لا تضع مفاتيح API داخل ملفات الواجهة أو APK؛ يجب حفظها كأسرار خادم.

## البناء
يُبنى APK تجريبي تلقائياً بواسطة GitHub Actions عند دفع تغييرات إلى فرع `moh-ai-cinema`. الملف الناتج APK تجريبي Debug وليس إصداراً موقعاً للنشر على المتجر.
